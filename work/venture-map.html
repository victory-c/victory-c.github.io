Bay Area Venture Map

Founder-facing reference for the Sand Hill Road venture cluster: interactive map + filterable table of VC firms, fed by a Python scraper pipeline.

  • ▪Deployed and live on Vercel
  • ▪Scraper pipeline → static map, no build step
  • ▪Found & fixed its own stored XSS
  • Python
  • Alpine.js
  • Leaflet
GitHub ↗Live ↗

The problem

Founders raising in the Bay Area keep re-deriving the same list: which firms sit on the Sand Hill Road / Menlo Park corridor, what stage and check size they actually write, and who to contact. That reference wanted to be one static page: an interactive map plus a sortable, filterable table — filter by AUM, stage, sector, and check size; click a pin for partner contacts and recent investments.

Demo

Architecture

Two deliberately small pieces:

  • scraper/ — a Python pipeline that reads a curated seed file, then optionally enriches it from public sources: SEC Form ADV (IAPD) for real AUM figures, OpenStreetMap Nominatim for geocoding (throttled to 1 req/s, as their usage policy asks). Output is a single firms.json.
  • site/ — a static page: vanilla HTML, Alpine.js for the table state, Leaflet for the map. No build step — the deployed site is just files.

The split means data problems and UI problems never tangle: the scraper has pytest coverage with mocked httpx transports (tests never hit the SEC), and the site consumes one JSON contract.

Engineering depth

The honest highlight: this project is where my security review practice caught a stored XSS in my own code. Firm names scraped from SEC filings flowed unescaped into Leaflet markers and tooltips — scraped government data is still untrusted input. The fix (escaping at the render boundary) landed as a merged, CI-green PR, and the lesson carried into how every other project here treats external data.

It's also the investor-facing piece of this site: a tool for founders, built from primary-source data, live at the link above.

What I learned

  • "No build step" is a real architecture choice with real benefits — the whole site is inspectable, deployable anywhere, and impossible to break in CI.
  • Data provenance is a feature: AUM from SEC filings with caveats beats confident numbers from nowhere.
  • Any data you didn't type yourself is untrusted, even when it comes from a regulator.
